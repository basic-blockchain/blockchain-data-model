# v2.8.2

## Summary

- Add end-to-end CLI demo script (`scripts/demo_cli.sh`) covering all 64 steps of v2.8.1 features.
- Script exercises the full feature surface: bootstrap, wallets, mint/transfer, exchange rates, treasury, policies, RBAC, moderation, user management, audit log, and integrity checks.
- Colored output with section headers, step counters, and expected-failure assertions.

## Included Changes

### `scripts/demo_cli.sh` (new)
- 64-step sequential CLI demo executed end-to-end against the JSON backend.
- Forces `PERSISTENCE_BACKEND=json` via `export` to prevent `.env` postgres override.
- Helper functions: `step`, `ok`, `note`, `adm` (with admin JWT), `pub` (unauthenticated), `expect_fail` (asserts non-zero exit for controlled failures), `jfield` (JSON field extraction via Python one-liner).
- Wallet IDs use the required 20–30 char format (`wallet_user_alice_utxo_01`, etc.).
- Sections:
  - Bootstrap & login (steps 1–8): register admin, create users, login, extract JWT.
  - Wallets (9–12): create UTXO and account wallets, balance queries.
  - Mint & transfer (13–21): mint funds, intra-model transfer, cross-currency preview.
  - Exchange rates (22–25): configure USD/EUR/USDX rates, list rates.
  - Treasury (26–30): create treasury wallets, top-up user wallets.
  - Policies & risk (31–40): set transaction limits, risk profiles, alert inspection.
  - RBAC (41–46): grant/revoke permissions by role and by user.
  - Moderation (47–52): freeze/unfreeze wallet, ban/unban user.
  - User management (53–58): update user, soft delete, restore, temp password.
  - Audit log & integrity (59–64): list audit entries, verify chain integrity, snapshot.

## Validation

- 213 unit tests passing, 0 failures.

## Notes

- `demo_cli.sh` is a developer tool and not part of the production API surface.
- `PERSISTENCE_BACKEND` in `.env` is intentionally overridden by the script; the `--store-file` flag is a no-op when postgres is the active backend.
