# v2.6.0

## Summary

- Cross-currency exchange with configurable conversion rates and commission percentages per pair.
- Corporate treasury wallet (`__TREASURY__`) with double-entry `top_up()` for wallet funding.
- Dynamic RBAC: per-role and per-user permission overrides stored in DB and JSON snapshot.

## Included Changes

### `domain/auth.py`
- Permissions added: `EXCHANGE`, `SET_EXCHANGE_RATE`, `TOP_UP`, `MANAGE_PERMISSIONS`.
- `has_permission()` extended with `role_overrides`, `user_permissions`, `user_id` kwargs.
- `effective_permissions()` helper returns the resolved permission set for a user/role.

### `domain/exchange.py` (new)
- `ExchangeRate` dataclass with `pair_key()`, `convert_amount()` returning gross/commission/net breakdown.

### `domain/multiuser_wallet_ledger.py`
- `set_exchange_rate()`, `get_exchange_rate()`, `list_exchange_rates()`.
- `ensure_treasury_user()`, `create_treasury_wallet()`, `list_treasury_wallets()`.
- `top_up()`: double-entry debit from treasury wallet, credit to target wallet.
- `grant_role_permission()`, `revoke_role_permission()`, `reset_role_permissions()`, `list_role_permissions()`.
- `grant_user_permission()`, `revoke_user_permission()`, `list_user_permissions()`.
- `transfer()` extended with exchange conversion when currencies differ.

### `migrations/versions/V004__exchange_rates.sql`
- `exchange_rates` table; `ALTER TYPE transfer_type ADD VALUE 'EXCHANGE'`; exchange metadata columns on `transfers`.

### `migrations/versions/V005__top_up_transfer_type.sql`
- `ALTER TYPE transfer_type ADD VALUE 'TOP_UP'`.

### `migrations/versions/V006__permissions.sql`
- `permissions` catalog, `role_permissions`, `user_permissions` tables with FK and indexes.

### `persistence/pg_multiuser_wallet_store.py`
- Fetch/upsert for exchange rates, role/user permission overrides.

### `scripts/multiuser_wallet_cli.py`
- Subparsers: `set-exchange-rate`, `list-exchange-rates`, `create-treasury-wallet`, `list-treasury-wallets`, `top-up`, `grant-permission`, `revoke-permission`, `grant-user-permission`, `revoke-user-permission`, `list-role-permissions`, `list-user-permissions`, `reset-role-permissions`.

### `scripts/multiuser_terminal.py`
- Sections EXCHANGE (23-24) and TESORERIA (25-27) added to ADMIN menu.
- Section PERMISOS (28-34): grant/revoke role and user permissions interactively.
- Transfer wizard shows conversion preview for cross-currency pairs.

### `tests/`
- `tests/test_exchange.py` (14 tests)
- `tests/test_corporate_wallet.py` (12 tests)
- `tests/test_dynamic_permissions.py` (19 tests)
