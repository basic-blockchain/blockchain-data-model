## Summary
This release establishes the first formal MVP baseline for the blockchain data model simulator.

## Included
- comparative simulator for UTXO and account-based models.
- realistic scenarios: coffee-export and retail-payments.
- JSON persistence split by model.
- run observability metrics.
- bilingual documentation package (ES/EN), including architecture, sequence flows, use cases, structures, and payload examples.

## Validation
- CI Pull Request checks passed on merged pull requests.
- core simulator tests executed successfully.
