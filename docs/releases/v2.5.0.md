# v2.5.0

## Summary
- Self-registration with role selection: ADMIN via invitation tokens, OPERATOR/VIEWER with activation codes.
- JWT authentication enforced on all CLI and terminal operations.
- Wallet ownership enforcement: non-ADMIN users can only access their own wallets.
- Terminal refactored from monolithic if-elif to Command Registry pattern.
- VIEWER role upgraded with create-wallet and transfer permissions.

## Included Changes
- `domain/auth.py`
  - VIEWER role now has CREATE_WALLET and TRANSFER permissions.
  - New functions: generate_invitation_token(), generate_activation_code().
- `domain/multiuser_wallet_ledger.py`
  - create_user() accepts role and invitation_token parameters.
  - New methods: generate_admin_invitation, validate_admin_invitation, activate_account, is_account_activated, is_empty.
  - login() validates activation code on first login for non-activated accounts.
  - Wallet transfer token TTL increased from 120s to 300s (5 minutes).
  - Improved cross-currency and cross-model error messages with specific currency/model names.
  - state_snapshot/from_snapshot include admin_invitation_tokens and activation_codes.
- `scripts/multiuser_wallet_cli.py`
  - New commands: register (with --role, --invitation-token), login (with --activation-code), generate-admin-token, assign-role, remove-role.
  - Global --token flag for JWT authentication on all commands.
  - Permission enforcement: ADMIN for user/policy/role ops, OPERATOR for mint, VIEWER for reads + transfer.
  - balance command optional --wallet-id: shows all user wallets when omitted.
- `scripts/multiuser_terminal.py`
  - Auth flow: [L] Login / [R] Register with role selector at startup.
  - Bootstrap: first user auto-becomes ADMIN.
  - Menus filtered by role: ADMIN (full + generate-admin-token), OPERATOR (wallets + mint + transfers + dashboard), VIEWER (wallets + transfers + dashboard).
  - Wallet ownership: non-ADMIN auto-selects from own wallets in balance, list-utxos, transfer, refresh-token.
  - main() refactored to Command Registry pattern (CommandContext, COMMAND_HANDLERS dict, _SkipCommand).
  - Dashboard available to all roles.
- `config/settings.py`
  - Auto-generate and persist JWT_SECRET to .env if missing.
  - JWT TTL default changed from 3600s to 1800s (30 minutes).
- `migrations/versions/V003__invitation_activation.sql`
  - New tables: admin_invitation_tokens, activation_codes.
- `persistence/pg_multiuser_wallet_store.py`
  - Persist/restore invitation tokens and activation codes.
  - Account activation saved on first successful login.
- Tests
  - 12 new self-registration tests (invitation tokens, activation codes, snapshot roundtrip).
  - 2 new cross-currency/cross-model transfer tests.
  - CLI tests updated with _bootstrap_admin helper and JWT auth flow.
  - 108 total tests passing.

## Validation
- `py -m pytest -m "not integration"` — 108 passing
- Manual verification: ADMIN, OPERATOR, VIEWER registration + login + wallet operations + ownership enforcement

## Notes
