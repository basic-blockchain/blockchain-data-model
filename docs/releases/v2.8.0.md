# v2.8.0

## Summary

- Full user lifecycle management: update user ID/name, soft delete (freezes wallets), restore.
- Temporary password flow: admin generates one-time password; user is forced to change on first login.
- Append-only audit log covering ~20 action types across all domain operations.
- User profile fields: first_name, last_name, email, username with `update_profile()`.
- Auto-generated sequential user IDs (`USR-00001`) with username-based identity resolution.

## Included Changes

### `domain/auth.py`
- Permissions added: `UPDATE_USER`, `DELETE_USER`, `RESTORE_USER`, `GENERATE_TEMP_PASSWORD`, `VIEW_AUDIT_LOG`, `UPDATE_PROFILE`.
- `generate_temp_password()`: 12-char random alphanumeric string.
- `generate_temp_token()`: 32-byte hex token.

### `domain/multiuser_wallet_ledger.py`
- `UserRecord` extended: `updated_at`, `deleted_at`, `first_name`, `last_name`, `email`, `username`.
- Credentials extended: `password_temp: bool`, `token_temp: str`.
- `_user_seq` counter + `_next_user_id()` → `USR-XXXXX` format; restored from snapshot.
- `resolve_user_id()`: looks up by user_id or username for login and token refresh.
- `update_user()`: ADMIN changes user_id or display_name.
- `delete_user()`: soft delete — sets `deleted_at`, freezes all wallets.
- `restore_user()`: clears `deleted_at`, optionally unfreezes wallets.
- `is_user_deleted()`.
- `generate_temp_password_for_user()`: generates and stores hashed temp password + token_temp.
- `change_password()`: verifies current password, updates hash, clears `password_temp`/`token_temp`.
- `reset_password_with_token()`: changes password using token_temp without knowing current password.
- `update_profile()`: updates first_name, last_name, email, username; logs USER_UPDATED.
- `self.audit_log: list[dict]` + `_audit()` private method called in ~20 existing methods.
- `list_audit_log()`: filter by action and/or user_id with configurable limit.
- `login()`: checks `deleted_at` before `banned`; returns `must_change_password: true` when `password_temp`.

### `migrations/versions/V008__audit_user_management.sql`
- `ALTER TABLE users ADD COLUMN updated_at TIMESTAMPTZ, deleted_at TIMESTAMPTZ`.
- `ALTER TABLE user_credentials ADD COLUMN password_temp BOOLEAN, token_temp VARCHAR(128)`.
- `CREATE TABLE audit_log` with indexes on timestamp, actor, action, target.

### `migrations/versions/V009__user_profile_fields.sql`
- `ALTER TABLE users ADD COLUMN first_name, last_name, email, username`.
- Unique index on `username`; standard index on `email`.

### `persistence/pg_multiuser_wallet_store.py`
- Fetch/upsert for `updated_at`, `deleted_at`, `password_temp`, `token_temp` with `_column_exists` guard.
- `_fetch_audit_log()` / `_sync_audit_log()`: append-only via `INSERT ON CONFLICT DO NOTHING`.
- Fetch/upsert for profile fields.

### `scripts/multiuser_wallet_cli.py`
- Subparsers: `update-user`, `delete-user`, `restore-user`, `generate-temp-password`, `change-password`, `reset-password-with-token`, `list-audit-log`, `update-profile`.
- `create-user` extended with `--first-name`, `--last-name`, `--email`, `--username`.

### `scripts/multiuser_terminal.py`
- Section GESTION DE USUARIOS (39-43) in ADMIN menu.
- `change-password` (44) and `update-profile` (45) available to all roles.
- Login flow forces password change when `must_change_password` is returned.
