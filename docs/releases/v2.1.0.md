# v2.1.0

## Summary
- Improves interactive console UX consistency for success and error feedback.
- Hardens transfer security in interactive mode by requiring explicit `sender_token`.
- Prevents uncaught Python tracebacks for invalid numeric input in transaction flows.

## Included Changes
- `scripts/multiuser_terminal.py`
  - Uniform alert blocks for all actions (`[SUCCESS]` / `[ERROR]`) with consistent header/body format.
  - Removes redundant `Error:` prefix from alert message body while preserving semantic error context.
  - Transfer and transfer-wizard now require explicit `sender_token` (no implicit session-token fallback).
  - Adds defensive numeric validation for `amount` and `fee` in `mint`, `transfer`, and transfer wizard paths.
  - Improves transfer feedback UX by showing immediate structured alerts without duplicated raw lines.
- `scripts/multiuser_wallet_cli.py`
  - Adds visual alert blocks for CLI success/error outcomes.
  - Adds argument-error JSON behavior when `--json` is set, while preserving visual alerts in stderr.
  - Reduces redundant wording in message body by trimming `Error:` prefix from alert message text.
- Tests
  - `tests/test_multiuser_terminal.py` updated with coverage for numeric guards, uniform feedback behavior, and security no-fallback behavior.
  - `tests/test_multiuser_wallet_cli.py` updated for CLI visual/JSON argument error handling and message formatting.

## Validation
- `py -m pytest -q tests/test_multiuser_terminal.py tests/test_multiuser_wallet_cli.py tests/test_multiuser_wallet_ledger.py`
- Result: passing

## Notes
- This release follows SemVer as a MINOR version because it introduces backward-compatible feature improvements and UX/security hardening without breaking public command contracts.
