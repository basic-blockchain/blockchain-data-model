# v2.3.0

## Summary
- Redesigns the interactive terminal with professional UX: ASCII banner, categorized menu, box-drawing layout, styled prompts, and structured data output.
- Adds 10 new terminal options for full feature parity with CLI mode.
- Fixes data box truncation for long values.

## Included Changes
- `scripts/multiuser_terminal.py`
  - ASCII banner with Bitcoin-style branding and version display.
  - Menu reorganized into 5 categorized sections: Users & Wallets, Transactions, Policies & Risk, Queries, System.
  - Box-drawing characters for all UI containers (menu, results, alerts, dashboard, token notices).
  - Styled prompts with color-coded indicators, hints, and default values.
  - Structured key-value data boxes for all operation results with proper width filling.
  - New options: list-users (12), balance (13), set-policy (14), get-policy (15), list-policies (16), set-risk-profile (17), get-risk-profile (18), list-risk-profiles (19), list-alerts (20), list-revisions (21).
  - Snapshot now displays summary counts instead of raw JSON dump.
  - Transfer wizard shows confirmation box with masked token.
  - Dashboard with Unicode meter bars and colored metrics.
  - Token notice box with expiration info on wallet creation.
- `scripts/multiuser_wallet_cli.py`
  - Maintained stable alert format for CLI mode (compatible with subprocess test assertions).
- `tests/test_multiuser_terminal.py`
  - Updated for new meter characters and prompt signature changes.

## Validation
- `py -m pytest -q -m "not integration"` — 75 passing
- Manual verification of all 21 terminal options

## Notes
- This release follows SemVer as a MINOR version because it adds 10 new interactive terminal features and a complete UX redesign without breaking any existing CLI command contracts.
