# v2.8.1

## Summary

- Technical debt resolution: eliminate DRY violations and SRP breaches across core modules.
- Extract `domain/precision.py` as single source of truth for `UNIT`/`SATOSHI`/`normalize_amount()`, removing four independent duplicate definitions.
- Extract `domain/blockchain_base.py` with `BaseBlockchain` class housing 18 methods shared between `UTXO_Blockchain` and `AccountBased_Blockchain`, eliminating ~300 lines of duplication.
- Extract `domain/utxo_operations.py` with pure UTXO selection functions decoupled from ledger state.
- Extract `scripts/terminal_ui.py` with 16 ANSI/UI helpers separated from command logic in the terminal.
- Deduplicate `OPERATOR_MENU` and `VIEWER_MENU` using shared section constants.

## Included Changes

### `domain/precision.py` (new)
- `UNIT = Decimal("0.00000001")`, `SATOSHI` alias, `normalize_amount()` — single canonical definition.
- Imported by `utxo-model.py`, `account-model.py`, `domain/exchange.py`, `domain/multiuser_wallet_ledger.py`.

### `domain/blockchain_base.py` (new)
- `Block` and `WalletKeys` dataclasses.
- `BaseBlockchain` with 18 shared methods: `_timestamp`, `_build_tx_id`, `_block_hash`, `_create_genesis_block`, `create_wallet`, `_ensure_wallet`, `_sign_payload`, `_verify_signature`, `mine_block`, `_refresh_confirmations`, `configure_compliance_profile`, `issue_certificate`, `record_logistics_event`, `audit_compliance`, `ledger_snapshot`, and validators.
- `UTXO_Blockchain` and `AccountBased_Blockchain` now inherit from `BaseBlockchain`.

### `domain/utxo_operations.py` (new)
- `select_utxos(utxos, currency, target_amount)`: greedy UTXO selection.
- `sum_utxos(utxos, currency)`: balance summation by currency.
- `consumed_utxo_ids(selected)`: extract IDs of spent UTXOs.
- `remove_consumed_utxos(utxos, ids_to_remove)`: filter out consumed entries.
- Used by `transfer()` and `top_up()` in `multiuser_wallet_ledger.py`.

### `scripts/terminal_ui.py` (new)
- 16 pure display helpers moved from `multiuser_terminal.py`: color/ANSI functions, box drawing (`_box_top`, `_box_mid`, `_box_bot`, `_box_line`, `_wrap_box`), result boxes, prompts (`_ask`, `_prompt`, `_prompt_confirm`), `_short_json`, `_meter`.

### `scripts/multiuser_terminal.py`
- Removed ~190 lines of inline UI helpers now imported from `terminal_ui`.
- `OPERATOR_MENU` and `VIEWER_MENU` built from `_SHARED_WALLETS`, `_SHARED_EXCHANGE`, `_SHARED_CONSULTAS`, `_SHARED_SISTEMA` shared section constants.

### `utxo-model.py` / `account-model.py`
- Replaced local `SATOSHI`/`UNIT`/`normalize_amount` definitions with `from domain.precision import ...`.
- `UTXO_Blockchain` and `AccountBased_Blockchain` now inherit from `BaseBlockchain`; model-specific methods only remain in each class.

## Validation

- 213 unit tests passing, 0 failures.
- No public API changes: class names, method signatures, error strings, and `state_snapshot()` key contracts unchanged.
- JSON and PostgreSQL persistence contracts preserved.

## Notes

- Pure internal refactoring — no user-visible behavior changes.
- Extractions of `ledger_serialization.py` and `ledger_auth.py` were evaluated and deliberately skipped: `from_snapshot()` is too entangled with instance construction, and JWT/password primitives are already isolated in `domain/auth.py`.
