# v2.4.0

## Summary
- Adds user authentication with bcrypt password hashing and JWT token generation.
- Introduces role-based access control (RBAC) with ADMIN, OPERATOR, and VIEWER roles.
- Extends the domain layer, PostgreSQL schema, and persistence store to support credentials and roles.

## Included Changes
- `domain/auth.py` (new)
  - Role and Permission enums with ROLE_PERMISSIONS mapping.
  - ADMIN has all permissions, OPERATOR can transfer/mint/view, VIEWER can only view.
  - hash_password() / verify_password() using bcrypt.
  - create_jwt() / decode_jwt() using PyJWT with HS256.
  - has_permission() for role-based authorization checks.
- `domain/multiuser_wallet_ledger.py`
  - create_user() accepts optional password parameter.
  - New methods: set_user_password, authenticate, login (returns JWT payload), assign_role, remove_role, get_user_roles.
  - state_snapshot() and from_snapshot() include credentials and roles.
- `migrations/versions/V002__auth_roles.sql` (new)
  - user_role ENUM type (ADMIN, OPERATOR, VIEWER).
  - user_credentials table with password_hash (bcrypt output).
  - user_roles table with composite PK (user_id, role).
- `persistence/pg_multiuser_wallet_store.py`
  - fetch/upsert for user_credentials and user_roles in PG backend.
- `config/settings.py`
  - New fields: jwt_secret, jwt_ttl_seconds, bcrypt_rounds.
- `requirements.txt`
  - Added bcrypt>=4.1 and PyJWT>=2.8.
- `.env.example`
  - Added JWT_SECRET, JWT_TTL_SECONDS, BCRYPT_ROUNDS.
- `tests/test_domain_auth.py` (new)
  - 19 test cases covering password hashing, JWT, RBAC, ledger integration, and snapshot roundtrip.

## Validation
- `py -m pytest -m "not integration"` — 94 passing (75 existing + 19 auth)
- Backward compatible: CLI and terminal work without passwords (optional parameter)

## Notes
- This release follows SemVer as a MINOR version because it adds backward-compatible authentication and RBAC features.
- JWT secret must be set via JWT_SECRET env var. Never hardcode credentials.
